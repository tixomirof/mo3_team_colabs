# Данные ML‑HW11

| Файл или папка | Содержимое |
| --- | --- |
| [resumes.csv](resumes.csv) | Корпус из 400 резюме. `index` — номер записи в исходном наборе, `text` — текст, `class` — категория, `candidate_id` — позиция в корпусе, из которой формируется ID `R1`–`R400`. Первые 18 записей совпадают с ML‑HW10. |
| [resumes_selected_raw/](resumes_selected_raw/) | 400 файлов вида `candidate_NNN_категория.txt`. В каждом указан номер кандидата, категория и полный текст резюме. |
| [indices.zip](indices.zip) | Готовые индексы базовой RAG и LongRAG, а также снимок графа LightRAG. [Ноутбук](../../labs/Lab06_ML-HW11_LongRAG_LightRAG_resumes.ipynb) загружает совместимые индексы из архива. |

## Содержимое `indices.zip`

В `faiss/` находятся два пакета. `resumes_no_tags/` индексирует 400 полных резюме для базовой RAG, а `longrag_chunks-256/` — 673 фрагмента длиной до 256 токенов для LongRAG. В каждом пакете четыре файла.

| Файл | Содержимое |
| --- | --- |
| `index.faiss` | Готовый векторный индекс для поиска. |
| `embeddings.npy` | Матрица векторов MiniLM в порядке объектов индекса. |
| `documents.json` | Тексты резюме или фрагментов в порядке индекса. |
| `meta.csv` | Метаданные объектов, включая номер исходной записи и номер кандидата. |

В `graph/` хранится снимок LightRAG.

| Файл | Содержимое |
| --- | --- |
| `graph_chunk_entity_relation.graphml` | Граф сущностей и связей со ссылками на исходные фрагменты. |
| `kv_store_doc_status.json` | Статусы индексации резюме и список фрагментов каждого документа. |
| `kv_store_full_docs.json` | Полные тексты резюме в хранилище LightRAG. |
| `kv_store_full_entities.json` | Список сущностей по каждому резюме. |
| `kv_store_full_relations.json` | Пары связанных сущностей по каждому резюме. |
| `kv_store_entity_chunks.json` | Соответствие сущностей исходным фрагментам. |
| `kv_store_relation_chunks.json` | Соответствие связей исходным фрагментам. |
| `kv_store_text_chunks.json` | Тексты фрагментов и привязка к резюме. |
| `vdb_chunks.json` | Векторное хранилище текстовых фрагментов. |
| `vdb_entities.json` | Векторное хранилище сущностей. |
| `vdb_relationships.json` | Векторное хранилище связей. |
